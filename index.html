☁️ Cloud Sync — มือถือ ↔ คอม

เชื่อมฐานข้อมูล RepairPro เดียวกันผ่าน Firebase Realtime Database ข้อมูลที่บันทึกจากเครื่องหนึ่งจะซิงก์ไปยังเครื่องอื่นแบบเรียลไทม์เมื่อออนไลน์
ยังไม่ได้เข้าสู่ระบบ Cloud
ยังไม่ได้เชื่อมต่อ Cloud
วิธีตั้งค่า Firebase
สร้าง Firebase Project → เพิ่ม Web App → เปิด Authentication แบบ Email/Password → เปิด Realtime Database → ตั้ง Security Rules ตามที่แอปแนะนำ → คัดลอก Web Config มาใส่ → ใช้อีเมล/รหัสผ่าน Cloud เดียวกันบนมือถือและคอม → ใช้ Shop ID เดียวกัน → กดเข้าสู่ Cloud แล้วเชื่อมต่อ
🔒 Security Rules สำหรับฐานข้อมูล
ใช้กฎนี้หลังเปิด Email/Password Authentication แล้ว เพื่อให้เฉพาะบัญชี Cloud เจ้าของ Shop ID เข้าถึงข้อมูลร้านได้
{
  "rules": {
    "repairpro": {
      "shops": {
        "$shopId": {
          ".read": "auth != null && data.child('ownerUid').val() === auth.uid",
          ".write": "auth != null && (!data.exists() || data.child('ownerUid').val() === auth.uid)"
        }
      }
    }
  }
}

⚠️ ล้างข้อมูลทั้งหมด

ข้อมูลทุกงานจะถูกลบออกจากเครื่องนี้ และไม่สามารถกู้คืนได้หากไม่มีไฟล์ Backup
